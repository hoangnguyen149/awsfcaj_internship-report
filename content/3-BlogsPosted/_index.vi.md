Tại đây sẽ là phần liệt kê, giới thiệu các blogs mà các bạn đã đăng trên [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj). Ví dụ:

###  [Blog 1 - Tối ưu chi phí hạ tầng AWS cho Web App](3.1-blog1/)
Chia sẻ kinh nghiệm tối ưu chi phí AWS cho hệ thống quản lý cho thuê văn phòng bằng cách kết hợp EC2 + AWS Lambda, áp dụng S3 Lifecycle/Glacier để lưu trữ dữ liệu cũ và sử dụng AWS Budgets & Cost Explorer để giám sát chi phí, giúp giảm ngân sách vận hành nhưng vẫn đảm bảo hiệu năng.

###  [Blog 2 - ...](3.2-blog2/)
Giới thiệu kiến trúc 3-tier trên AWS sử dụng Application Load Balancer, Auto Scaling Group và RDS Multi-AZ nhằm tăng khả năng chịu tải, tự động mở rộng tài nguyên và đảm bảo hệ thống luôn sẵn sàng khi xảy ra sự cố.

###  [Blog 3 - ...](3.3-blog3/)
Chia sẻ cách triển khai Amazon Cognito để quản lý người dùng, phân quyền theo vai trò, tích hợp API Gateway Authorizer và IAM Least Privilege, giúp tăng cường bảo mật đồng thời giảm thời gian phát triển tính năng xác thực người dùng.
