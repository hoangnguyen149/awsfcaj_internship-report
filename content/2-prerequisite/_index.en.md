## Prerequisites

Before starting the workshop, you need:

### AWS Account
- Active AWS account
- IAM permissions to create and manage resources
- AWS Region: **ap-southeast-1 (Singapore)** *(recommended)*

### Required Knowledge
- Basic understanding of AWS Console
- Basic knowledge of [related technology]

### Tools to Install
- [AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html) v2+
- Modern web browser (Chrome, Firefox, Edge)

{{% notice info %}}
All resources in this workshop are created in region **ap-southeast-1**.
{{% /notice %}}
