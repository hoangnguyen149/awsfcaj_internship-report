## Clean Up Resources

{{% notice warning %}}
**Important:** Delete all resources after completing the workshop to avoid unexpected charges.
{{% /notice %}}

### Deletion Order

Delete in reverse order to avoid dependency errors:

#### 1. Delete [Resource Name 2]

1. Go to **AWS Console** → **[Service Name]**
2. Select the resource
3. Click **Delete** and confirm

#### 2. Delete [Resource Name 1]

1. Go to **AWS Console** → **[Service Name]**
2. Select the resource
3. Click **Delete** and confirm
